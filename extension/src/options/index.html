Explicitly Supported Contexts

AgentBreak Sentinel only operates on verified and tested AI interfaces:

  • AgentBreak Local Test Fixture: Synthetic Demo Chat (file://*demo_chat.html) Supported
  • Local Development Servers: http://localhost:* & http://127.0.0.1:* Supported
  • ChatGPT Web Interface: https://chatgpt.com/* Supported
  • Claude Web Interface: https://claude.ai/* Supported

All other websites will display as "Unsupported or Idle" to respect user privacy and avoid false assumptions.

Privacy & Architecture Commitments

Zero Passive Tracking: AgentBreak Sentinel does NOT log your browsing history, intercept network traffic, collect passwords, or read session cookies. All inspections are explicitly initiated by you via the extension popup.

Important Security Distinction: The Sentinel extension performs prompt-level pattern analysis. It can identify high-risk phrasing like "ignore all rules" or detect canary tokens. However, only the full AgentBreak Sandbox with deterministic guards can verify whether an attack succeeded against a real tool execution policy.
